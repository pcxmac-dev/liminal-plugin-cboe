# Changelog

## 1.2.0 (2026-10-31)

- Released as its own package, `massive-plugin-cboe`, registered under the entry point group
  `massive_collate.providers`; its version is the distribution's.
- Its plan and request caps are in it (`TIER`, `PER_RUN`, `PER_DAY`), no longer in the app's
  `config.PUBLIC_FEEDS`.
- Plugin API 1.6.

## 1.1.0 (2026-10-31)

- Built into massive-collate: its source class and client in its module (plugin API 1.6).

## 1.0.0 (2026-10-29)

- Built into massive-collate: the first versioned release (plugin API 1.0).
